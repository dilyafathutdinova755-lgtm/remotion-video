# Эксперимент: визуализация условия сосудами (ЕГЭ, проф. математика №10)

Отдельный локальный прототип **вне контент-завода**: не использует
`task_data.json`/`align.py`/`build-dynamic-task.mjs`/n8n/Postmypost — целиком
закодирован вручную в `MathVesselsMain.tsx`/`timing.ts`, зарегистрирован как
отдельная Remotion-композиция `MathVesselsExperiment` (см. `src/Root.tsx`).

## Задача

«К 8 кг десятипроцентного раствора соли добавили тридцатипроцентный раствор
той же соли. Сколько килограммов тридцатипроцентного раствора нужно добавить,
чтобы получить двадцатипроцентный раствор?» — ответ 8 кг (см. `README` отчёт
в чате сессии за точное решение).

## Что внутри

- `timing.ts` — измеренный тайминг (секунды каждой реплики чернового аудио,
  НЕ оценка на глаз — см. ниже).
- `Vessel.tsx` — 2,5D стеклянный сосуд (SVG: градиент стекла, блик, мениск,
  контактная тень). В проекте нет Three.js/WebGL-библиотек — настоящая 3D-
  сцена не использована сознательно (так и написано в ТЗ: 2,5D при
  отсутствии инструментов).
- `MathVesselsMain.tsx` — одна непрерывная сцена: условие (сосуды появляются
  по смыслу реплик) → пауза 2с → 3 шага решения.
- `CtaScene.tsx` — финальный экран (логотип/"Скачивай бесплатно") — та же
  визуальная композиция, что и у остальных роликов, без TaskContext.
- `generate-audio.mjs` — пересобирает `public/audio/experiment-math-vessels.mp3`
  (требует `espeak-ng`, локально и бесплатно — `apt-get install espeak-ng`).

## Озвучка — ЧТО ЭТО и чем не является

Черновой голос **espeak-ng** (офлайн, бесплатно) — НЕ ElevenLabs, НЕ
production-голос, НЕ production-нормализатор n8n (тот не тронут и не
использован). Нужен был исключительно чтобы получить **реальные**, измеренные
секунды для синхронизации, а не гадать на глаз. Каждая реплика синтезирована
отдельно, её длительность измерена `ffmpeg`, финальный трек — конкатенация
этих файлов + тишины заданной длины (включая обязательные ровно 2.000с после
условия). `timing.ts` совпадает с построением файла 1:1 — пересчитывать
forced alignment не нужно.

Если понадобится пересобрать: `node src/experiments/math-vessels/generate-audio.mjs`.

## Известные упрощения / что ещё стоит проверить

- Голос — черновой, заметно роботизированный (качество espeak-ng).
  Для демонстрации идеи достаточно, для публикации — нет.
- Камера — 2D-трансформации (scale/translate), не настоящая 3D-камера.
- Вертикальное пространство под сосудами используется не полностью —
  можно дособрать компоновку плотнее после визуальной оценки на реальном
  телефоне.
- Референсов было изучено 1 из 3 (остальные два не были приложены к моменту
  сборки этого прототипа) — стиль можно скорректировать после них.
