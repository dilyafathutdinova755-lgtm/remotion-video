# Договорённости по роликам

Решения, принятые заказчиком, которые нужно применять к новым роликам.
Здесь только то, что не видно из кода.

## Сцена ответа — только там, где не было разбора

Если у задачи есть пошаговый разбор, отдельная сцена ответа не нужна:
последний шаг уже приводит к ответу, и повторять его на следующем кадре —
дублирование. После последнего шага сразу идёт финальный кадр с приложением.

- **Без сцены ответа** (есть разбор): профильная математика, базовая
  математика, информатика, биология.
- **Со сценой ответа** (разбора нет, ответ и есть развязка): русский
  задание 6, русский задание 7, история задание 19.

Следствие, о котором надо помнить при переделке: пояснение сейчас живёт на
сцене ответа (`check`). Если сцену убрать, пояснение придётся переносить в
последний шаг разбора — иначе оно пропадёт вместе со сценой.

Включается полем `answerRecap: false`. Уже переведены: профильная математика
(`profile10.tsx`, `ship200`, `twoCars`). Ждут переезда при следующем
перерендере: базовая математика, информатика, биология.

## Прочее

- Звука в роликах нет.
- Отдельного кадра с таймером нет ни у одного предмета; там, где нужно время
  подумать, оно добавляется в конец сцены с условием.
- Фраза «Решаем задание из приложения „ЕГЭ тренажёр“» остаётся в сценариях
  озвучки, но не выводится на экран.
- Иконка приложения синяя при любой палитре — это бренд.
