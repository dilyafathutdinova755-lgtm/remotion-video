# Завод роликов-объяснялок (experiments/vessels-3d) — обязательные правила

Эти правила действуют для КАЖДОГО нового ролика и каждой раскадровки по любому
предмету. Утверждённые версии (ветки `*-approved-*`, `history-baked-v2`) не
переделывать задним числом.

## Шапка кадра (всегда, во всём ролике и в раскадровке)

1. Белая плашка «ЕГЭ ТРЕНАЖЁР» или «ОГЭ ТРЕНАЖЁР» с настоящей объёмной иконкой
   приложения — сверху (top 138), **стоит на месте с первого кадра**.
   ЕГЭ и ОГЭ — разные бренды: и иконка, и название на плашке, и иконка в финале
   идут по экзамену из `TASK.exam`. Иконки: ЕГЭ — `ru/logo.png`,
   ОГЭ — `assets/logo-oge.png` (собрана из настоящей иконки скриптом
   `make_logo_oge.py`; если появится оригинальный файл иконки ОГЭ — заменить им).
2. Под ней — точки шагов (top 272).
3. **Под точками — плашка «экзамен · предмет · задание N»**, например
   «ОГЭ · физика · задание 6» (top ≈ 302, маленькая, спокойная, в цвете предмета).
   Видна весь ролик, гаснет вместе с точками в финале. Экзамен — ЕГЭ или ОГЭ,
   предмет — строчными, номер — номер задания из банка. Как в продакшене
   (`src/ege/scenes/HookVisual.tsx`: «ЕГЭ · предмет · задание N»).
   В коде сцены задаётся одной константой `TASK = { exam, subject, number }`
   (пример: `phys/scene.js`). Экзамен и номер задания НЕ угадывать по теме — брать из задания или
   спросить у пользователя (ошибка была: физика ОГЭ №6 подписана как «ЕГЭ · задание 2»).
4. Заголовки шагов («Шаг 1 из 3» + название) — ниже этой плашки (top 372).

## Начало и конец

- **Никакой заставки с вращением иконки.** Ролик сразу начинается с
  визуализации условия; голос стартует через ~0,2 с.
- Финал: плашка сворачивается, объёмная иконка вылетает крупно в центр,
  «Больше заданий / в приложении — бесплатно», кнопка «Скачивай бесплатно»,
  «Ссылка в профиле ↑». Название приложения в финале не дублировать.
- Иконка — только настоящий логотип, всегда объёмный (3D).

## Стиль

- На экране только то, что важно сейчас; отыгранное исчезает.
- Плашки с текстом маленькие и спокойные. Условие — ровным текстом.
- Пауза: всё условие одной карточкой + таймер «Ставь на паузу», кольцо 4 → 1. Без размытия.
- Один основной цвет на предмет.
- Каждое слово условия проиллюстрировано.
- Найденный ответ встаёт в иллюстрацию (ярлык переворачивается); отдельного слайда с ответом нет.

## Рендер и озвучка

- Ролик всегда с голосом (RHVoice, временная озвучка допустима). Убрать голос
  нельзя без предупреждения: тайминг завязан на голос.
- Полный рендер 1080×1920 60 fps — ~25 мин. Перед долгим рендером сказать,
  сколько он займёт. Если правка касается только начала/конца — сначала
  предложить быстрый вариант (обрезка готового MP4 через ffmpeg, ~1 мин).
- Ничего не подключать к автоматизации (n8n, Actions, Postmypost), рабочие
  ветки не трогать. Эксперименты — только в `experiment/math-vessels-visual`.
