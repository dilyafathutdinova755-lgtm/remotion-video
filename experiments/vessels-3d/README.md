# Эксперимент: «Сосуды 3D» — свой рендер, без Remotion

Отдельный локальный прототип (ЕГЭ, профильная математика №10, задача про
растворы соли). Не связан с контент-заводом: n8n, `align.py`, GitHub Actions,
Postmypost и рабочие ветки не используются и не затрагиваются.

## Чем сделано

- **3D** — Three.js (WebGL): стеклянные мензурки (материал с френелем и
  отражениями окружения), жидкость с уровнем, который остаётся горизонтальным
  при наклоне (мировая плоскость отсечения), струи при переливании, кристаллы
  соли, логотип приложения как толстая глянцевая плитка, мягкие тени.
- **2D-слой** — HTML/CSS: цветовые «миры» фона с большими движущимися
  свечениями (по референсу), плашка, точки прогресса, заголовки со сменой
  через размытие, стикеры прямо на стекле, заметки с печатью текста,
  уравнение, где члены «перелетают» между строками.
- **Рендер** — `render.mjs`: headless Chromium (WebGL через SwiftShader)
  покадрово вызывает `window.renderFrame(t)` (всё — чистая функция времени),
  кадры идут в ffmpeg. Несколько воркеров параллельно, 60 fps. Быстрые
  вращения логотипа — с настоящим motion blur (усреднение подкадров).
- **Логотип** — настоящая картинка из приложения (`assets/logo.png`, вырезана
  по форме иконки), а не нарисованная копия.
- **Голос** — RHVoice (голос «Татьяна»), офлайн и бесплатно. Каждое
  предложение синтезируется целиком; момент каждого ключевого слова
  измеряется (синтез префикса), и визуальные события стоят ровно на словах.
- **Звук** — эффекты и тихий эмбиент синтезированы в `make_mix.py` (numpy),
  без внешних сервисов.

## Как собрать

```bash
apt-get install -y rhvoice rhvoice-russian ffmpeg
pip install numpy pillow
cd experiments/vessels-3d && npm install
python3 make_audio.py            # assets/voice.wav + timeline.json
node render.mjs stills 2.6 30    # контрольные кадры → out/
node render.mjs video --workers 3 --fps 60   # out/video-silent.mp4
python3 make_mix.py              # out/final.wav
ffmpeg -i out/video-silent.mp4 -i out/final.wav -c:v copy -c:a aac -b:a 192k -shortest out/vessels-3d.mp4
```

## Файлы

- `src/story.js` — тайминг из `timeline.json` и цветовые миры по разделам.
- `src/choreo.js` — хореография сосудов (позиции, наклоны, налив).
- `src/world3d.js` — 3D-сцена.
- `src/overlay.js` — 2D-слой.
- `make_audio.py`, `make_mix.py`, `render.mjs` — голос, звук, рендер.
