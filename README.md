# ЕГЭ тренажёр — видеоразбор задачи 10

Ролик на [Remotion](https://remotion.dev): разбор задачи 10 профильного ЕГЭ по
математике (про кепки и футболки). Вертикальный формат под Shorts / Reels /
TikTok, бело-синее оформление, без озвучки.

## Структура ролика

Композиция `Task10` — 1080×1920 (9:16), 30 fps, 1977 кадров (1:06).

| Сцена | Длительность | Что происходит |
| --- | --- | --- |
| Титры | 6 с | Иконка приложения, «Решаем задачу из приложения ЕГЭ тренажёр», заголовок |
| Условие | ~16,4 с | Текст задачи, подсвечивается только читаемое сейчас слово |
| Таймер | 8 с | Условие на экране, отсчёт 5 секунд, призыв поставить паузу |
| Решение 1 | 10 с | Обозначения, `3y = 0,55 · 2x = 1,1x` → `30y = 11x` |
| Решение 2 | 12,5 с | `x = 30t`, `y = 11t`, `68t = 1020`, `t = 15` |
| Ответ | 7 с | `x − y = 19t = 285` и проверка |
| Финал | 6 с | Иконка приложения, «Скачивай бесплатно», ссылка в шапке профиля |

Фон живёт вне `<Series>`, поэтому не мигает на стыках сцен. Плашка в углу
висит до финального экрана, где её заменяет большая иконка приложения.

## Ход решения

Через отношение цен, без дробей и без решения системы:

1. `3y = 0,55 · 2x = 1,1x`, домножаем на 10 → `30y = 11x`.
2. Значит `x : y = 30 : 11`, то есть `x = 30t`, `y = 11t`.
3. `3x − 2y = 90t − 22t = 68t = 1020` → `t = 15`.
4. `x − y = 30t − 11t = 19t = 285`.

Проверка: `t = 15` даёт `x = 450`, `y = 165`; `3 · 165 = 495 = 0,55 · 900` ✓
и `1350 − 330 = 1020` ✓.

## Вёрстка под вертикаль

`SAFE` в `theme.ts` задаёт безопасную зону: интерфейс Reels/Shorts перекрывает
верх (шапка) и низ (подпись, кнопки), поэтому сцены центрируются внутри этой
полосы, а не по всему кадру. Плашка «ЕГЭ тренажёр» опущена под шапку.

## Логотип

`src/ege/AppLogo.tsx` — иконка приложения, собранная вектором (синий сквиркл
с сеткой, «ЕГЭ» и «ТРЕНАЖЁР»). В маленьком размере включается `compact`:
подпись убирается, иначе она превращается в нечитаемую кашу.

Если появится оригинальный PNG — положите его в `public/` и замените тело
компонента на `<Img src={staticFile("logo.png")} />`, остальной код трогать
не нужно.

## Разработка

```bash
npm i
npm run dev      # студия Remotion
npm run lint     # eslint + tsc
```

Ключевые файлы:

- `src/ege/timing.ts` — весь тайминг. Длительность сцены с условием считается
  из массива слов: каждое слово подсвечивается пропорционально своей длине,
  поэтому текст можно править, не пересчитывая кадры руками.
- `src/ege/theme.ts` — палитра и шрифты.
- `src/ege/scenes/` — по файлу на сцену.
- `src/ege/ProblemText.tsx` — текст задачи; используется и в сцене чтения
  (с подсветкой), и в сцене таймера (без неё).
- `src/ege/fontFaces.ts` — сгенерированный список `@font-face`; правится не руками,
  а через `node scripts/fetch-fonts.mjs`.

## Шрифты

Три семейства в связке: **Montserrat** (жирные заголовки), **Inter**
(основной текст и формулы, включая курсив для переменных) и **Oswald** —
узкий вытянутый гротеск для плашек и подписей. Светлые начертания (300)
разбавляют жирные, чтобы картинка не выглядела тяжёлой.

Подмножества «кириллица + латиница» лежат в `public/fonts` и подключаются
через `staticFile()` в `src/ege/FontGate.tsx`. Локальные копии нужны, чтобы
рендер не зависел от сети, а `FontGate` придерживает рендер через
`delayRender()`, пока шрифты не загрузятся — иначе первые кадры выходят
системным шрифтом.

Обновить набор:

```bash
node scripts/fetch-fonts.mjs
```

```bash
npx remotion render Task10 out/zadacha-10.mp4 \
  --browser-executable=/путь/к/headless_shell
```
